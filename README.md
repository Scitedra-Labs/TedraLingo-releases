## עברית

TedraLingo מתחילה בשפה מדוברת לחו״ל וממשיכה לדקדוק עד רמה B1. יש בה מורים, הקראה עוקבת, מצב צב, הברות ותעתיק בכתב שלכם, בדיקת הגייה חיה, שיחות עם דמויות ומורה AI.

- **שפות ללימוד:** אנגלית · ערבית (מדוברת, ואפשר גם ספרותית) · צרפתית · ספרדית · עברית · איטלקית · גרמנית
- **ממשק:** עברית · English · العربية · Русский

## English

TedraLingo starts with spoken language for travel and goes on to grammar up to B1. It has teachers, karaoke reading, turtle mode, syllables and transliteration in your own script, live pronunciation checks, conversations with characters and an AI teacher.

- **Learn:** English · Arabic (spoken, with Standard on demand) · French · Spanish · Hebrew · Italian · German
- **Interface:** Hebrew · English · Arabic · Russian

### Download & install

| Platform | How |
|---|---|
| 🌐 Browser | [Open in browser](https://scitedra-labs.web.app/tedralingo/app). Nothing to install; Google sign-in and cloud save |
| 🤖 Android | [Download the APK](https://github.com/Scitedra-Labs/TedraLingo-releases/raw/apk/TedraLingo.apk). Android asks you to allow installs from this source |
| 📱 iPhone & iPad | Open the app in Safari → Share → “Add to Home Screen” |
| 💻 Mac | In Safari: File → “Add to Dock”. In Chrome or Edge: the install icon in the address bar |

Product page: https://scitedra-labs.web.app/en/tedralingo/

### Current version

**v26**
- German: 10 stops, 10 character conversations, 10 grammar units and a teacher from Berlin
- 4 new B1 units in each of the seven languages
- A review after every 5 stops
- Community: a weekly league by tier, friends and invite links
- Android home-screen widget
- Google sign-in goes through scitedra-labs.web.app

The APK is a test build (debug-signed). If a build with a different signature is installed, uninstall it first.
